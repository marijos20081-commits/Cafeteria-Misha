Cafetería-Misha
Anexo: Cómo ejecutar el programa (para el docente)

Este es un programa de escritorio hecho con Python y Tkinter. No se abre desde el navegador: debe ejecutarse en una computadora que tenga Python instalado. A continuación se detallan los pasos para abrirlo.

Requisitos

Python 3.8 o superior.
Tkinter (viene con Python en Windows y macOS; en Linux puede ser necesario instalarlo).
Instalación de Tkinter en Linux (si se necesita)

En Debian/Ubuntu: sudo apt update sudo apt install python3-tk
Pasos para ejecutar

Guarde el archivo si.pyen una carpeta del equipo (o clonar el repositorio).
Abrir una terminal (o símbolo del sistema) y ubicarse en esa carpeta.
Ejecutar el comando:
En Windows (si pythonapunta a Python 3):
python si.py
En macOS/Linux o si pythonapunta a Python 2:
python3 si.py
Qué sucede al ejecutar

Se abrirá la ventana "Cafetería Misha". Desde ahí se puede presionar "Registrarse" para crear una cuenta (rol Recepcionista o Cocina) y luego iniciar sesión para probar el sistema.
Nota: los datos (usuarios, pedidos, inventario) se guardan solo en memoria mientras el programa está abierto; al cerrarlo se pierden.
